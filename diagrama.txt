

Cliente (navegador, app, curl)

  ▼
URLs + Router                     → decide qué vista atiende la ruta
  ▼
Vista (ViewSet)                   → capa de PRESENTACIÓN: HTTP, permisos, códigos de estado
  │       ▲
  │       └── Serializer          → traduce JSON <-> objetos y valida el formato de la entrada
  ▼
Servicio (TaskService)            → capa de NEGOCIO: reglas, cálculos, coordinación
  ▼
Repositorio (TaskRepository)      → capa de ACCESO A DATOS: consultas
  ▼
ORM de Django → SQL → Base de datos
